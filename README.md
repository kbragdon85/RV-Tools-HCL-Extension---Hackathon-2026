# RV-Tools HCL Extension - Hackathon 2026
Extension for RV-Tools that will do a HCL Compatability check agianst currently public HCL
This is provided As-Is with no warranty implied or given. This was created as part of Explore 2026 Hackathon.
Use at your own risk.
Copy the Invoke-VcfHclAssessment powershell script to the RVTools directory
Copy the Interactive-execution powershell script to the RVTools directory
Run the Interactive Execution powershell script and provide credentials
